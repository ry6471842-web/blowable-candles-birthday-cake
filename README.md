🕯️ Blow the Candle — Interactive Pixel Art Birthday Experience

A fun interactive birthday web experience built with **CSS pixel art** and microphone input. Light up the moment by blowing into your microphone — just like a real birthday candle! 🎂

The project detects your breath through the microphone and makes the pixel-art candle flame react and blow away when you blow. Share the link with friends and let them make a wish too!

## ✨ Features

* 🕯️ Interactive pixel-art candle created with CSS
* 🎤 Microphone-based blow detection
* 💨 Real-time candle flame reaction
* 🎂 Birthday-themed experience
* 📱 Shareable with friends for virtual birthday wishes
* 🎨 Lightweight and runs directly in the browser

🛠️ Technologies Used

* HTML5
* CSS3 (Pixel Art)
* JavaScript
* Web Audio API (Microphone input)

 🚀 How to Run

1. Clone this repository:


2. Open the project folder.

3. Run in your browser.

4. Allow microphone permission when prompted.

5. Blow into your microphone and watch the candle react! 🕯️

🎮 How It Works

This project is designed as a small digital birthday surprise that you can send to friends and family. Instead of a physical candle, they can blow on a virtual pixel-art candle and make a wish from anywhere.
